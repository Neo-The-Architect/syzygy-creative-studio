# Contributing

Keep changes small, reproducible, and evidence-bound.

Before editing:

1. state the bounded outcome;
2. identify the affected package and owner;
3. preserve unrelated changes;
4. keep external effects disabled in tests;
5. add a focused regression test for each defect.

Pull requests should include the exact commands run, test totals, known
limitations, and whether the change is implemented, tested, integrated, or
runtime verified. Do not claim production readiness from a local fixture.
